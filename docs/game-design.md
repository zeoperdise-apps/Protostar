# PROTOSTAR / AUTONOMOUS COMBAT LAB

日本語中心のブラウザ用オートバトル・ロボット実験室。原作の16×16 AIチップと分岐矢印を完成させる。ストーリー、3Dモデル、対人ネット対戦、課金を入れず、強い編集可能なプリセットとの試行錯誤と自作AI同士の対戦に集中する。

技術構成はVite + TypeScript + Three.js。描画は正投影の純2D、操作画面はDOM。60 Hzの固定tick、乱数シードを持つ純TSシミュレーションを描画から独立させる。画面は戦闘ラボ、AIワークベンチ、機体庫。音は後段のWebAudio効果音。

アリーナ960×640、障害物あり。前後移動・旋回・敵/障害物のセンサー・HP/エネルギー/武器診断・左右独立武器を、実際のAIチップとして実装する。各命令は時間を消費し、無限ループは有限予算で安全停止。機体と弾は壁・障害物・機体に衝突し、弾は線分で衝突判定する。敵は必ず別オブジェクトとして独立複製する。

機体はスカウト85HP、バランス100HP、フォートレス130HP。武器はパルス8ダメージ/.65秒/射程360、レール22/1.8秒/520、スキャッター3×6/1.2秒/240。エネルギーは行動で消費・常時回復。射撃は向きの左右18°以内だけ照準補正する。死亡で終了、90秒で残HP率→与ダメージ→引分。左右同時の着弾を公平に処理する。

プリセット6段階は射撃訓練機、追跡機、双砲機、回避機、狙撃機、最終適応機。全て初めから選択でき、勝利徽章を保存。最終適応機は重装甲＋双レール＋エネルギー診断。初期自作機は追撃/双砲/回避の3体で、編集なしで実戦可能。装備や戦法に相性があり、全機に対する単一の必勝構成は保証しない。

保存はバージョン付きlocalStorage JSON。利用不能ならメモリ継続、破損時は初期サンプルへ復旧。機体と全保存データのJSON入出力はサイズ・型・有限数値・装備・盤サイズ等を検証する。詳細は`docs/api.md`。
