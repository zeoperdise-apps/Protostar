# PROTOSTAR — AUTONOMOUS COMBAT LAB

日本語 · [English](README.en.md)

16×16のチップと分岐矢印でAIを組み、ロボットを自律対戦させる日英対応ブラウザゲームです。2010年のJava ME試作を参考に、未実装だった後退・診断・左右武器、機体庫、対戦相手、勝敗、保存と編集を完成させています。ストーリーやネット対戦はありません。

## 起動

Node.js 22.12以上（検証: Node.js 24）。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。開発サーバーは `0.0.0.0:5173` で待ち受けます。本番ファイルは `npm run build` で `dist/` に生成できます。ゲーム本体に外部画像・フォント・通信サービスへの依存はありません。

本番ビルドをローカル確認する場合:

```sh
npm run build
npm run preview -- --port 4173
```

`http://localhost:4173` を開きます。配布時は `dist/` の内容を静的HTTPサーバーへ配置してください。相対アセットURLのためサブパスへの配置も可能です。`file://` で直接開かず、HTTPで配信してください。

## 表示言語

ヘッダーまたは開いているダイアログの **JA / EN** で切り替えます。新規保存はブラウザ言語が `ja*` なら日本語、それ以外は英語で始まります。選択は保存され、JSONの入出力にも含まれます。言語設定のない旧保存は日本語で読み込みます。切替で戦闘・装備・選択セル・undo履歴は失われません。

機体名は利用者のデータです。保存済み・入力した日本語名を英語表示で自動変更しません。新しい初期機体とプリセットを新規複製した機体だけ、作成時の言語で名前を付けます。

## 遊び方

1. **機体を選ぶ**: 初期機体3体はすぐに対戦できます。「機体庫」でフレーム3種と左右それぞれの武器3種を選べます。ステータスと説明を見て戦法に合わせてください。
2. **戦法を試す**: 「バトル」で6体のプリセットを選び、「対戦開始」。自作AI同士の対戦や同じ機体同士も可能です。撃破、または90秒経過で決着します。時間切れは残HP率、与ダメージの順で判定します。プリセットへの勝利はローカルに記録します。
3. **AIを改良する**: 「AIワークベンチ」でセルを選び、パレットからチップを配置。インスペクターでパラメーターと通常/YES/NOの矢印を設定します。変更は自動保存され、次の対戦に適用されます。

一時停止、0.1秒（6 tick）ステップ、1/2/4倍速、同条件リセットでAIを観察できます。実行トレースは現在セル・分岐・直近命令と射撃の不発を表示します。センサー表示は、現在実行したセンサーチップの設定範囲とYES/NOを表示します（他の命令では非表示、空リンクで再起動した場合は結果未記録と表示）。前方は設定半角・距離600、近距離は設定距離、左は距離600の左半面です。敵検知は遮蔽物を判定に考慮しますが、範囲図は遮蔽で切り抜きません。障害物検知は前方88の中心線と、障害物・敵機を自機半径+3だけ広げた接触境界、壁から自機半径の境界を表示します。対戦中の設計変更は次の対戦から表示にも反映されます。

Spaceで停止/再開（フォーム入力中を除く）。画面切替やブラウザの非表示時は停止します。盤上の選択セルにフォーカスしてDeleteで削除。Ctrl/Cmd+Zまたは元に戻すボタンで最大100回取り消せます。盤はスクロール・拡大縮小・全体表示に対応します。操作の説明と19チップの一覧はヘッダーの「ガイド」から開けます。

## AIの接続ルール

- STARTを1個置きます。通常矢印は上下左右の隣接セルへ進みます。
- 条件チップはYESとNOの矢印を別々に設定します。
- ENDはSTARTへ戻ります。JUMP A〜Eは対応するLABEL A〜Eへ移動します。
- 空白・盤外へ出る矢印はSTARTへ戻ります。空リンクなどの警告があっても実行できます。
- START不足・重複や未定義LABEL等のエラーは対戦前に表示し、開始をブロックします。無限の制御チップループはエンジンが安全に停止します。
- 左右武器は独立して冷却します。冷却中やエネルギー不足の発射命令は不発となり、次の命令へ進みます。

プリセットは直接変更されません。テンプレートの複製は新規機体を作ります。既存のAIを無言で上書きしません。

## 保存・JSON

機体・AI・設定・勝利記録はこのブラウザのlocalStorage（`protostar.save.v1`）に保存します。アカウントやサーバー保存はありません。保存を利用できない環境ではメモリに切り替わり、画面上に表示します。ブラウザのデータ削除に備えて機体庫の「全データ出力」を使ってください。

単体機体JSONを入力すると新しいIDで追加します（最大24機）。全保存JSONの入力は、内容を検証してから上書き確認を表示します。不正ファイルは現在の保存内容を保持します。入力は1MBまで。最後の1機は削除できません。

## 実装

Vite + TypeScript + Three.js。描画は**正投影の完全2D**です。3Dモデル・3Dボックス・ライト・遠近カメラは使いません。機体・床はcanvasで生成した2Dテクスチャ、弾・軌跡・センサーは平面と線です。WebGLが利用できない場合は説明を表示し、機体・AI編集は続けられます。音はユーザー操作後だけ開始する任意のWebAudio効果音です。

- `src/game/`: 描画から独立した固定60 Hzのシミュレーション、AI、当たり判定とシード付き乱数
- `src/data/`: 6プリセットと3初期機体の実行可能なAI
- `src/render/`: snapshotを読むだけのThree.js 2D描画、DPR上限、リサイズ、context lifecycle
- `src/ui/`: DOMのバトル・AIエディター・機体庫、固定tick accumulatorとbounded catch-up
- `src/audio/`: 任意の射撃・命中・結果音
- `src/storage/`: バージョン付き保存とJSON検証

詳細: [設計](docs/game-design.md)、[エンジン/保存API](docs/api.md)。

## 検証

```sh
npm run typecheck
npm test
npm run balance
npm run build
```

`npm test` は29件のエンジン/保存/センサー描画/日英互換テスト、`npm run balance` は63対戦の完走・与ダメージ検証です。

ブラウザQAは開発サーバー起動後、`node scripts/playtest.cjs`。Playwright coreとChromiumのインストール場所はスクリプト先頭に記載しています（現在のCloud環境ではインストール済み）。初期画面、戦闘結果、編集/undo/保存/再読込、装備変更、自作同士、JSON入出力、デスクトップ/390px表示、ブラウザエラーを検証し、`artifacts/qa-report.json` とスクリーンショットを生成します。画像だけの再生成は `node scripts/screenshot.cjs`。`artifacts/` はローカルの検証記録です。

最終の本番QA・配布物・検証制約は [最終QA記録](docs/qa-final.md) に記載しています。

日英の録画なしQAは `node scripts/i18n-playtest.cjs`、続けて `node scripts/i18n-edge-playtest.cjs`。状態保持、翻訳漏れ、保存互換、390px表示を検証し、`artifacts/i18n-*` に画像とレポートを生成します。詳細は [日英QA記録](docs/qa-i18n.md)。既存の日本語ブラウザQAスクリプトはブラウザ言語を日本語に固定しています。
